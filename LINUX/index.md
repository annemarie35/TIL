# Determine processor architecture on Linux
To determine your processor architecture, paste in the following command into your terminal:
```shell
uname -m
```

- x86_64 : If the output is x86_64 then you are on a 64-bit architecture.
- i686 : If the output is i686 then you are on a 32-bit architecture.
